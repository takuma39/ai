`contents/` の1セクションから、勉強会スライドの原稿を生成します。

対象セクション: $ARGUMENTS

## 前提として必ず読むもの

1. [`../slide-standards.md`](../slide-standards.md) — **骨格・記法・Canva 制約**。この規約から外れた原稿を作らないこと
2. `slide/README.md` — デッキ一覧と想定尺
3. 対象セクションの `contents/$ARGUMENTS/README.md` と配下の全 md

## 実行手順

### ステップ1: 素材の棚卸し

対象ディレクトリの全ファイルを読み、次を抽出する。

| 抽出するもの | どこから |
| --- | --- |
| **1文の takeaway** | 各記事の「結論」節を通読して1つに集約する |
| 課題提起に使える具体例 | 「背景・課題」節 |
| プロンプト実例（3〜5個） | 「実際のプロンプト例」節 |
| **失敗例・注意点** | 「注意点」節 — ★ここが差別化になる。必ず拾う |

### ステップ2: 捨てる

**記事の情報量の7割は捨てる。** 残す3割の選定基準：

- takeaway を支えないものは落とす
- 表・コード・Mermaid が主役の内容は、平文に落とせなければ Appendix か `contents/` 誘導に回す
- 迷ったら Appendix に送る（本編から消すのではなく後ろに送る）

### ステップ3: 骨格に流し込む

`slide-standards.md` の「デッキの共通骨格」に従って配置する。

- 本編 **20〜25枚** + Appendix
- **#2「今日持ち帰るもの」と #9「まとめ」は完全に同じ文**にする。言い換えない
- 「次の一歩」は**1つだけ**。3つ書かない

### ステップ4: 1枚ずつ書く

| 項目 | 基準 |
| --- | --- |
| タイトル | 全角20字以内。**主張**を書く（「〜について」で終わらせない） |
| 本文 | 全角120字以内・箇条書き3項目まで |
| 数字 | 1枚に1つ |

**⚠️ 最重要**：`description` になる平文に、**コマンド・設定キー・オプション名・バージョン番号・厳密な数値を書かない**。Canva 側の AI にリライトされて壊れる。これらは図（Mermaid）の中に置くか `visual: manual` に回す。

### 図は Mermaid で書く

**「Canva で〜な図を描いて」という日本語指示を書かない。** ```` ```mermaid ```` ブロックにソースを書く。

- 既定は `visual: mermaid`。**図のないスライドが例外**
- 登場人物の間のやりとり（手戻り・レビューの往復）は **`sequenceDiagram`**、工程の流れは **`flowchart`**
- 強調は `<!-- fig: -->` のコメントではなく **`classDef` で書く**（`hi` = 強調、`dim` = 減光）
- 書き終えたら **`./slide/render-figures.sh <deck>` を実行し、エラー0を確認**してから報告する
- 生成された PNG は `slide/_assets/<deck>/` に入る。**Canva へのアップロードは人がやる**（自動化できない）

### ステップ5: 発表者ノートを書く

`<!-- note: -->` に、会場への問いかけ・言い方の注意・予想される質問・時間の目安を書く。
**スライドに書けなかった内容の置き場にしない。**

### ステップ6: 自己チェック

`slide-standards.md` の「公開前チェックリスト」を上から順に検証し、結果を報告する。特に：

- 図が**10枚以内**か（Canva の `asset_ids` 上限）
- `render-figures.sh` が**エラー0**で通るか
- 失敗例チャプターが空でないか
- 参考リンクが実在パスか

### ステップ7: 索引の更新

`slide/README.md` のデッキ一覧の「状態」列を `未着手 → 執筆中` に更新する。

## 出力

- `slide/$ARGUMENTS.md`（ASCII ファイル名）
- 生成後に**スライド枚数・画像点数・想定尺**を報告する

## 注意事項

- 必ず日本語で作成すること
- **記事の要約を作らない。** 抜粋 + 誘導で作る
- Canva へは流さない。**この skill の成果物は人間のレビュー待ちの原稿**である
- 元記事にない主張を足さない。足したくなったら、まず `contents/` 側に書く
